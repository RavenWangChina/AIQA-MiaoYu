# BUG 报告模板（failed/broken 二分——Allure 对齐）
- BUG ID：SWAN-BUG-YYYYMMDD-NNN
- 任务ID/来源轮次：
- **分类：failed（断言失败，产品缺陷）/ broken（环境/工具故障，非产品缺陷）**
- 模块/用例名/文件行号：
- 基线（仓库@commit）：
- 复现步骤：
- 预期 vs 实际：
- **复现计数：n/m**（真实计数，不夸大）
- flaky 标记：是/否（是→同步登记 03d）
- 证据（截图/日志/录屏路径）：
- 严重级（S1致命~S4轻微）初判：（**命名规范**：严重级用 S1-S4；测试级别 L1-L4 是执行范围（冒烟/功能/场景/探索），两者严格区分，禁止用 Lx 表达严重度）
- **缺陷管理系统单号**：（提单后填；未提单标 local）
- 修复验证状态：待验证/已验证关闭/打回
