## 二、10 分钟上手

1. **恢复状态**：读 `docs\qa-knowledge\00-索引.md` + `session-state.md`——项目在哪、待办什么、未决什么，全在这两个文件。
2. **注入主对话**（外部协调通道）：
   ```
   $prompt | & $codex exec --skip-git-repo-check -m [MODEL] `
     -c sandbox_mode="danger-full-access" resume 01a05af8-ca6e-7b63-bab5-4d64993067b6 -
   ```
   注意：注入前锁探测（用户开着桌面主对话时勿注入）；prompt 经 stdin。
3. **派任务**：主对话按 `docs\workflow\qa\task-split-rules-v1.md` 拆卡 → spawn 独立会话以卡为唯一授权（stdin 传卡）。
4. **找东西**：模板 `workflow\qa\templates-v2\`（32个）· 知识 `qa-knowledge\` · 结果 `results\<任务ID>\` · 审计 `workflow\qa\audit-log.md`。
5. **规矩速记**：证据=完成（BLOCKED≠失败）· 产出中文 · 工具链互斥 · 心跳5分钟 · 覆盖缺口/定级争议/不可逆=报用户。
