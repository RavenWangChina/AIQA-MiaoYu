# 03c BUG 状态跟踪表（本地状态机 x 禅道状态映射）

> 本地知识库是资产主库，禅道是协同面（J6/F4）。每个 BUG 一行，状态流转在此驱动。

| BUG编号 | 标题 | 本地状态 | 禅道单号 | 禅道状态 | 验证轮次 | 下一步动作 | 更新日期 |
|---------|------|----------|----------|----------|----------|------------|----------|
| BUG-2026-09-02-001 | （示例）配网后列表不刷新 | 待验证 | #1234 | 已解决 | R-2026-09-05 | 跑回归验证 | 2026-09-05 |

## 本地状态机
新建 → 复核（双通道复核通过）→ 已提单（禅道 MCP 提单回填单号）→ 待验证（禅道状态=已解决 时触发）→ 关闭（回归验证过）/ 打回（回归不过，回到待验证并评论禅道）。已关闭的 BUG 再次复现 → 重开。

## 禅道状态映射
| 禅道状态 | 本地动作 |
|----------|----------|
| 激活/处理中 | 无动作（等待） |
| 已解决 | 触发回归验证轮（05e 回归触发登记） |
| 已关闭 | 本地同步关闭 |

## 轮询规则（禅道 MCP 是拉不是推）
定时查"状态=已解决 且 指派=我"（30min到1h）+ 本表比对——禅道变了才触发验证。
